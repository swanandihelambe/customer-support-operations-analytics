# Dataset

This project uses the **IT Support Tickets — 100K synthetic SaaS helpdesk tickets** dataset from Kaggle.

## Dataset Details

- **Source:** Kaggle
- **Dataset:** Synthetic IT Support Tickets
- **Records:** 100,000
- **Original columns:** 20
- **Time period:** 2022–2025
- **Data type:** Synthetic

The dataset contains customer-support ticket information including:

- Ticket metadata
- Customer segments
- Support channels
- Product areas
- Issue types
- Priority
- Ticket status
- SLA plans
- Resolution time
- Reopen status
- Customer sentiment
- CSAT scores
- Platform
- Region

## Dataset Availability

The original CSV files are not included in this GitHub repository to keep the repository lightweight.

The dataset can be obtained from the original Kaggle source:

**Kaggle:**  
https://www.kaggle.com/datasets/ahsanneural/synthetic-it-support-tickets

After downloading the dataset, place the raw CSV at:

```text
data/raw/synthetic_it_support_tickets.csv
```

The cleaned dataset generated by the project is saved as:

```text
data/cleaned/customer_support_cleaned.csv
```

## Data Processing

The dataset is cleaned and transformed using:

```text
src/data_cleaning.py
```

The processing includes:

- Datetime conversion
- Missing-region handling
- Time-based feature engineering
- Resolution/backlog classification
- Resolution-time band creation

The resulting dataset is then used for PostgreSQL loading, SQL analysis, and Python-based exploratory analysis.
